# 📊 EXPLORATORY DATA ANALYSIS (EDA)

## 📌 Overview
This project focuses on performing Exploratory Data Analysis (EDA) to understand the structure and characteristics of a dataset. It involves analyzing data types, handling missing values, identifying patterns, trends, and outliers, and visualizing relationships between variables.

---

## 🎯 Objectives
- Understand dataset structure and variables  
- Identify missing values and data inconsistencies  
- Discover patterns and trends  
- Detect outliers and anomalies  
- Analyze relationships between variables  

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## ⚙️ Steps Performed
1. Data Loading and Inspection  
2. Data Cleaning (handling missing values, duplicates)  
3. Statistical Summary  
4. Data Visualization (histograms, boxplots, heatmaps)  
5. Correlation Analysis  
6. Insights and Observations  

---

## 📊 Visualizations Used
- Histogram → distribution of data  
- Boxplot → outlier detection  
- Heatmap → correlation between variables
